¿Qué es CSS?

CSS (Cascading Style Sheets o Hojas de Estilo en Cascada) es el lenguaje que se utiliza para definir el diseño, la apariencia y la presentación visual de una página web escrita en HTML. Mientras que HTML se encarga de la estructura y el contenido (los textos, imágenes y botones), CSS determina cómo se ve ese contenido: colores, fuentes, tamaños, márgenes, animaciones y la distribución de los elementos en la pantalla.

¿Qué aprenderé en este curso?

Aprenderás a diseñar y maquetar sitios web completos de forma profesional. El temario incluye desde los fundamentos (colores, fuentes, modelo de caja) hasta tecnologías modernas como Flexbox, CSS Grid, Animaciones y la optimización de código con Sass.

¿Qué herramientas o programas voy a necesitar?

Solo necesitas un navegador web (como Google Chrome o Mozilla Firefox) y un editor de código gratuito como Visual Studio Code. En las primeras clases te enseñamos a instalarlo y configurarlo.
